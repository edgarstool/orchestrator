# Research Workflow

## 觸發

- 需要先查資料再決定的任務
- 技術選型、第三方工具評估
-  investigating 問題根因

## 步驟

1. 指揮官確認 research scope，開 kanban card，指派 `researcher`
2. `researcher` 回傳 findings + sources
3. 指揮官 judge 夠不夠：
   - 夠 → 進入下一步（通常接 implementer）
   - 不夠 → 補派 researcher 或自己擴大 scope
4. 若結論直接可執行，指揮官直接分解成 implementer 任務

## 檢查點

- [ ] findings 有來源，不是推測
- [ ] sources 是一手文件 / 原始 repo，不是二手部落格
- [ ] 結論有明確的 recommendation
- [ ] 未經證實的內容有標注

## 注意

- researcher 不回實作，只回證據與建議
- scope 由指揮官控制，researcher 不要擅自擴大
